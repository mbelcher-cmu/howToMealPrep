# Claude skills

The design and animation skills in this folder are vendored from
[emilkowalski/skills](https://github.com/emilkowalski/skills) at commit
`c8a79627b59d72d764d6ab6f2c87c09a48169833` (MIT, see `LICENSE-emilkowalski`).
They are plain Markdown instructions; Claude Code loads them automatically when
working in this repo. To update, re-copy the `skills/` folder from upstream.
